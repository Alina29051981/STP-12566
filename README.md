# Trailer Park Boys Match Landing Page

Responsive landing page for the mobile game inspired by _Trailer Park Boys
Match_.

## Features

- Responsive layout for mobile and desktop
- Smooth scrolling navigation
- FAQ accordion with animation
- Character cards with glow hover effects
- Reviews section with adaptive grid
- Blurred background effects
- SVG sprite icons
- Google Play download button
- Optimized images with retina support

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- SVG Sprite
- Responsive Design
- Flexbox & Grid
- Vite
